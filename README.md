# Aula Digital-Proyecto Intermodular SMX

Transformación de una aula tradicional en una aula digital: mobiliario específico para
ordenadores, armario rack con switch y router, rosetas RJ 45 a la pared para una red de
área local con intercomunicación entre el alumnado y el profesorado, salida a Internet,
pizarra digital e impresora de red.
